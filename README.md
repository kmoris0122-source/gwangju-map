# 🍽️📸 광주 밥약 &amp; 포토스팟 맵

광주·전남의 **밥약집 / 카페 / 포토스팟**을 한 장에 모아두고, 오늘 갈 한 곳은 **🎲 랜덤 룰렛**으로 골라주는 모바일 퍼스트 개인 지도. v4에서 **지도 보기**가 붙었다.

- 순수 HTML / CSS / JS — 빌드 없음. 지도 라이브러리(Leaflet 1.9.4 + markercluster)만 `vendor/`에 직접 넣어 오프라인에서도 뜬다
- 아이폰 홈 화면에 추가하면 앱처럼 열림 (PWA, standalone)
- 장소 데이터는 `data/places.json` 한 파일만 고치면 반영됨

## 데이터 스키마 (`data/places.json`)

배열 하나이며, 각 항목은 아래 필드를 가집니다.

| 필드 | 값 |
| --- | --- |
| `id` | 고유 문자열 (영문 슬러그 권장) |
| `name` | 상호명 / 스팟 이름 |
| `area` | `수완지구` · `첨단` · `상무지구` · `동명동` · `양림동` · `봉선동` · `전남대/용봉동` · `광주 기타` · `전남 근교` · `전국/타지역` |
| `category` | `밥약/식사` · `카페` · `포토스팟` · `술집` · `혼밥` |
| `status` | `wishlist`(가볼 곳) · `favorite`(또 갈 곳) |
| `address` | 도로명 주소 |
| `phone` | 전화번호 (없으면 빈 문자열) |
| `hours` | 영업·운영 시간 (브레이크타임·라스트오더·휴무일 포함) |
| `parking` | 주차 정보 |
| `priceRange` | 가격대 (포토스팟은 입장료) |
| `signature` | 추천 메뉴 (포토스팟은 촬영 포인트) |
| `note` | 한줄평 / 메모 |
| `lat` / `lng` | 위도·경도 (지도 핀 좌표, 소수 6자리) |
| `mapQuery` | 네이버 지도 검색어 (장소명 + 지역 키워드) |
| `mapUrl` | 지도 링크 — `https://map.naver.com/p/search/<URL 인코딩된 mapQuery>` |
| `addedAt` | ISO 8601 시각 — 마지막 업데이트 표시와 정렬에 사용 |

### 좌표

`lat`/`lng`는 카카오·구글 지도 API(`maps` CLI)로 잡았다. 주소 지오코딩 결과와 장소 검색 결과를 서로 대조해
200m 이내로 일치하면 장소 검색 좌표(매장 단위)를, 아니면 직접 확인한 좌표를 쓴다. 149곳 전부 좌표가 있고,
모두 한국 범위(위도 33~39, 경도 124~132) 안에 있다. 확인 스크립트는 `python3`로 돌렸고 결과는 커밋 메시지에 적었다.

### 장소 추가하는 법

1. `data/places.json`에 항목을 하나 더 넣습니다 (`id`는 겹치지 않게). `lat`/`lng`를 꼭 채웁니다.
2. `area`·`category`는 위 값 중 하나를 그대로 씁니다. 새 동네가 필요하면
   `index.html`의 `AREAS` 배열에도 같은 이름을 추가해야 필터 칩이 생깁니다.
3. 커밋·푸시하면 GitHub Pages에 반영됩니다. (서비스 워커는 페이지·데이터를 네트워크 우선으로 받아옵니다.)

## 로컬에서 보기

```bash
# 저장소 루트에서
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

`file://`로 바로 열면 `fetch`가 막혀 데이터가 보이지 않습니다. 간단한 서버로 열어 주세요.
지도 타일(CARTO)만 네트워크가 필요하고, Leaflet은 `vendor/`에 있어 오프라인에서도 라이브러리는 뜹니다.
