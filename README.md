# 🍽️📸 광주 밥약 &amp; 포토스팟 맵

광주·전남의 **밥약집 / 카페 / 포토스팟**을 한 장에 모아두고, 오늘 갈 한 곳은 **🎲 랜덤 룰렛**으로 골라주는 모바일 퍼스트 개인 지도.

- 순수 HTML / CSS / JS — 빌드 없음, 의존성 없음
- 아이폰 홈 화면에 추가하면 앱처럼 열림 (PWA, standalone)
- 장소 데이터는 `data/places.json` 한 파일만 고치면 반영됨

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 상단 요약 | 전체 장소 수 · 가볼 곳 · 또 갈 곳 · 마지막 업데이트 |
| 필터 | 동네 / 종류 / 상태 칩 + 검색창 |
| 카드 | 동네·종류·상태 배지, 주소, 영업시간, 주차, 전화, 가격대(또는 입장료), 추천 메뉴(포토스팟은 촬영 포인트), 한줄평, 🗺️ 네이버 지도 |
| 🎲 랜덤 룰렛 | 지금 필터에 걸린 장소 중 하나를 애니메이션으로 뽑아 추천 |
| 개인 기록 | 다녀옴 체크 · 상태 변경 · 개인 메모를 `localStorage`에 저장 (이 기기에만) |

## 데이터 스키마 (`data/places.json`)

배열 하나이며, 각 항목은 아래 필드를 가집니다.

| 필드 | 값 |
| --- | --- |
| `id` | 고유 문자열 (영문 슬러그 권장) |
| `name` | 상호명 / 스팟 이름 |
| `area` | `수완지구` · `첨단` · `상무지구` · `동명동` · `양림동` · `광주 기타` · `전남 근교` · `전국/타지역` |
| `category` | `밥약/식사` · `카페` · `포토스팟` · `술집` · `혼밥` |
| `status` | `wishlist`(가볼 곳) · `favorite`(또 갈 곳) · `visited`(방문함) |
| `address` | 도로명 주소 |
| `phone` | 전화번호 (없으면 빈 문자열) |
| `hours` | 영업·운영 시간 (브레이크타임·라스트오더·휴무일 포함) |
| `parking` | 주차 정보 |
| `priceRange` | 가격대 (포토스팟은 입장료) |
| `signature` | 추천 메뉴 (포토스팟은 촬영 포인트: 골든아워·구도·특징) |
| `note` | 한줄평 / 메모 |
| `mapQuery` | 네이버 지도 검색어 (장소명 + 지역 키워드) |
| `mapUrl` | 지도 링크 — `https://map.naver.com/p/search/<URL 인코딩된 mapQuery>` |
| `addedAt` | ISO 8601 시각 — 마지막 업데이트 표시와 정렬에 사용 |

### 장소 추가하는 법

1. `data/places.json`에 항목을 하나 더 넣습니다 (`id`는 겹치지 않게).
2. `area`·`category`는 위 값 중 하나를 그대로 씁니다. 새 동네가 필요하면
   `index.html`의 `AREAS` 배열에도 같은 이름을 추가해야 필터 칩이 생깁니다.
3. 커밋·푸시하면 GitHub Pages에 반영됩니다. (서비스 워커는 데이터를 네트워크 우선으로 받아옵니다.)

## 장소 목록 (105곳)

모두 Google 지도·카카오맵, 네이버 플레이스 등록 정보, 운영기관(관광공사·지자체·국립공원) 안내에서

지도 버튼은 **네이버 지도 검색**으로 열려요. 검색어는 `장소명 + 지역 키워드`(예: `크림집 광주 광산구`, `죽녹원`)로 장소마다 다듬었고,
네이버 플레이스에 등록되지 않은 곳은 도로명주소를 검색어로 쓴다. `mapQuery`만 고치면 링크도 따라 바뀐다.
확인한 실제 장소입니다. 처음 9곳은 `note`에 `샘플 추천`으로 표시되어 있습니다.

## 로컬에서 보기

```bash
# 저장소 루트에서
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

`file://`로 바로 열면 `fetch`가 막혀 데이터가 보이지 않습니다. 간단한 서버로 열어 주세요.

## GitHub Pages

- 저장소 → Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `/ (root)`
- 주소: `https://kmoris0122-source.github.io/gwangju-map/`
- `.nojekyll`이 있으므로 Jekyll 처리 없이 정적 파일 그대로 배포됩니다.

## 아이폰 홈 화면에 추가

Safari로 페이지를 연 뒤 **공유 → 홈 화면에 추가**. 아이콘과 이름(광주 밥약맵)이 붙고,
주소창 없이 전체 화면으로 열립니다.
